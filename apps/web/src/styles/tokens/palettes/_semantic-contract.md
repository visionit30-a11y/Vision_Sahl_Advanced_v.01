# عقد الرموز اللونية الدلالية

كل لوحة مرشّحة تعرّف **نفس مجموعة الأسماء الدلالية** أدناه. المكونات لا تعرف اللوحة
ولا تستخدم قيمة لونية صريحة إطلاقًا — تستخدم هذه الأسماء فقط. لذلك تغيير الهوية لاحقًا
تغيير قيم في ملف واحد، لا إعادة كتابة مكونات.

بعد اختيار مالك المشروع للوحة واحدة تُدمج في `tokens/color.css` وتُحذف بقية المرشحات.
