# موديولات المجال

هذا المجلد فارغ في Phase 0 عن قصد.

كل موديول لاحق (`governance/`, `finance/`, `beneficiaries/` ...) يملك نماذجه وخدماته وقواعده،
ويتواصل مع غيره عبر **واجهات خدمة** أو أحداث مجال داخلية — وليس باستيراد طبقة تخزين موديول آخر.
