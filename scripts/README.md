# سكربتات التشغيل

سكربتات جسر التنفيذ (ADR-0004). تُشغَّل بـ **زر يمين على الملف ← Run with PowerShell**،
وكل سكربت يكتب سجلًا كاملًا في مجلد `_logs\` باسم السكربت وتاريخ التشغيل.

| السكربت | الغرض | يُشغَّل متى |
|---|---|---|
| `00-check.ps1` | تقرير قراءة فقط عن أدوات الجهاز وحالة المشروع. لا يغيّر شيئًا. | أولًا، وعند أي شك في البيئة |
| `01-setup.ps1` | تهيئة `.env`، البيئة الافتراضية، حزم الخلفية والواجهة، إنشاء دور وقاعدة PostgreSQL، وتطبيق المهاجرات | مرة واحدة، ويمكن إعادته بأمان |
| `02-run.ps1` | تشغيل الخلفية والواجهة في الخلفية وطباعة رابط المراجعة | عند كل مراجعة |
| `03-test.ps1` | تشغيل كل بوابات الجودة: ruff, mypy, pytest, eslint, tsc, vitest, build | قبل إغلاق أي مرحلة |
| `04-git-sync.ps1` | دفع الفروع إلى المستودع الرسمي على GitHub | عند إتاحة الاتصال بـ GitHub |
| `05-stop.ps1` | إيقاف الخدمات التي شغّلها `02-run.ps1` فقط | عند الانتهاء |

## ضمانات السلامة

- لا حذف خارج مجلد المشروع، ولا حذف خطير داخله.
- لا تعديل لإعدادات نظام Windows.
- لا تثبيت برامج على مستوى الجهاز — كل تثبيت داخل `.venv` و`node_modules` للمشروع.
- كلمة مرور PostgreSQL تُطلب مرة واحدة بشكل مخفي، ولا تُكتب في أي سجل.
- كلمة مرور قاعدة بيانات التطبيق تُولَّد عشوائيًا وتُحفظ في `.env` غير المتعقّب في Git.
- `04-git-sync.ps1` لا ينفذ Force Push ولا يعيد كتابة التاريخ إطلاقًا.

## ملاحظة

`_logs\` مستثنى من Git، ومحتواه للتشخيص فقط.
