# فهرس وثائق منصة سهل المطور

## المصدر الرسمي الملزم

الوثيقتان التاليتان في **جذر المشروع** هما المرجع الأعلى والوحيد، ولا توجد منها نسخة ثانية
داخل `docs/` تجنبًا لتعدد المصادر واختلافها مستقبلًا:

| الوثيقة | المسار | الرمز |
|---|---|---|
| متطلبات الأعمال | `../BRD_منصة_سهل_المطور_عقد_تنفيذ_صارم_Claude_Code_v1.3.docx` | BRD-SAHEL-001 |
| المواصفات التقنية | `../SRS_منصة_سهل_المطور_عقد_تقني_مرحلي_Claude_Code_v1.3.docx` | SRS-SAHEL-001 |

عند أي تعارض بين الكود وهاتين الوثيقتين، الوثيقتان هما المرجع.
BRD يحدد **لماذا** و**ماذا**، وSRS يحدد **كيف** وبأي **ترتيب**.

## قاعدة تحديث الوثائق

- لا يُعدَّل BRD أو SRS من داخل المشروع.
- كل قرار لم تحسمه الوثيقتان يُسجَّل كـ ADR جديد ولا يبقى في المحادثة فقط.
- كل مكتبة جديدة تُسجَّل في `dependencies.md` مع سبب إدخالها.
