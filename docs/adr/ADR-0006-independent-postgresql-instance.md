# ADR-0006: خادم PostgreSQL مستقل تمامًا عن Odoo

- **الحالة:** معتمد
- **التاريخ:** 2026-09-05
- **القرار من:** مالك المشروع

## السياق

جهاز التطوير يشغّل خدمة `PostgreSQL_For_Odoo` على المنفذ 5432، وهي جزء من تثبيت Odoo.
كان بالإمكان إنشاء قاعدة ودور معزولين داخلها، لكن ذلك يخلق تبعية خفية لمنصة سهل على
تثبيت Odoo: أي ترقية أو إزالة لـ Odoo تكسر بيئة سهل، وتصبح دورة حياة الخادم خارج سيطرة
المشروع.

## القرار

1. منصة سهل تستخدم **خادم PostgreSQL مستقلًا خاصًا بها**، منفصلًا في التثبيت والخدمة
   والـ cluster والمنفذ.
2. **يُحظر** على أي سكربت أو إعداد في المشروع استخدام أو تعديل أو إيقاف خدمة
   `PostgreSQL_For_Odoo`، أو أي قاعدة أو دور أو إعداد تابع لـ Odoo.
3. المنفذ الافتراضي لمنصة سهل محليًا هو **5433**، لأن 5432 مشغول بخادم Odoo.
4. لا تُعدَّل متغيرة PATH على مستوى Windows؛ يُكتشف مسار أدوات PostgreSQL داخل السكربتات.
5. **حارس تنفيذي إلزامي:** قبل أي عملية إنشاء، يستعلم سكربت التهيئة عن `data_directory`
   للخادم المتصل به، ويتوقف فورًا دون تغيير أي شيء إذا كان المسار يخص Odoo. القرار مطبق
   في الكود وليس في التوثيق فقط.
6. مجلد البيانات المتبقي في `C:\Program Files\PostgreSQL\15\data` (من تثبيت سابق أزيلت
   ثنائياته) **لا يُستخدم ولا يُحذف ولا يُلمس**؛ ليس ملكًا لهذا المشروع.

## التبعات

- بيئة سهل المحلية قابلة للنقل والحذف دون أثر على Odoo، والعكس صحيح.
- الانتقال لاحقًا إلى قاعدة بيانات مُدارة على OCI لا يتطلب فك ارتباط بأي نظام آخر.
