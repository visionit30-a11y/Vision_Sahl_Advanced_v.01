# ADR-0004: جسر التنفيذ عبر سكربتات PowerShell

- **الحالة:** معتمد (إجراء مؤقت)
- **التاريخ:** 2026-09-05

## السياق

الوكيل البرمجي يستطيع تأليف الملفات داخل جذر المشروع وإدارة Git محليًا، لكنه لا يستطيع في
البيئة الحالية تنفيذ أوامر على ويندوز (الطرفيات ممنوحة بصلاحية النقر فقط)، ولا الوصول إلى
مستودعات الحزم أو GitHub من الصدفة المتاحة له.

## القرار

1. تُنشأ سكربتات PowerShell في `scripts/` تغطي: الفحص، التهيئة، التشغيل، الاختبار، ومزامنة Git.
2. يشغّل مالك المشروع السكربت المطلوب بنقرة، وتُكتب كل المخرجات في `_logs/`.
3. يقرأ الوكيل السجلات مباشرة من `_logs/` ويتولى التشخيص والإصلاح.
4. **هذا قيد أدوات تنفيذ وليس قرارًا معماريًا**: لا يغيّر Stack ولا المعمارية ولا استراتيجية Git
   ولا متطلبات الجودة.
5. متى أصبح التنفيذ المباشر متاحًا، يعود الوكيل إليه تلقائيًا ولا يُطلب تشغيل السكربتات بلا حاجة.

## قيود السلامة الملزمة على السكربتات

- لا حذف خارج مجلد المشروع، ولا حذف خطير داخله.
- لا تعديل إعدادات نظام Windows.
- لا تثبيت برامج على مستوى الجهاز.
- كل تثبيت يقتصر على البيئة الافتراضية للمشروع (`.venv`) وحزم الواجهة (`node_modules`).
- لا تُكتب كلمات المرور في السجلات إطلاقًا.
