# ADR-0008: الهوية الافتراضية للمنصة

- **الحالة:** معتمد
- **التاريخ:** 2026-09-05
- **القرار من:** مالك المشروع

## القرار

1. **الهوية الافتراضية للمنصة:** `teal-calm` — «تيل هادئ برأس ملوّن».
2. **لا تُحذف أي هوية.** الهويتان الأخريان تبقيان خيارين متاحين.
3. **يُوسَّع العدد إلى خمس هويات** بإضافة اثنتين ضمن محرك التخصيص — **Phase 1B-1**، لا الآن.
4. كل هوية تلتزم بنفس عقد الرموز الدلالية، ولا يعرف أي مكوّن اسم الهوية العاملة.

## المعرّفات

معرّفات وصفية ثابتة، لا أرقام تفقد معناها عند إعادة الترتيب أو الإضافة:

| المعرّف النهائي | الوصف | المعرّف المؤقت في Phase 1A |
|---|---|---|
| `teal-calm` | تيل هادئ برأس ملوّن — **الافتراضية** | `c` |
| `green-institutional` | أخضر مؤسسي هادئ برأس وتنقل فاتحين | `a` |
| `navy-institutional` | كحلي مؤسسي بتنقل جانبي داكن | `b` |

Phase 1A تعمل بالمعرّفات المؤقتة `a` / `b` / `c`. **الترحيل إلى المعرّفات الوصفية جزء من
`themeRegistry` في Phase 1B-1**، ولم يُنفَّذ الآن حتى تبقى النسخة المعروضة للمراجعة مطابقة
تمامًا لما اجتاز البوابات.

## القيد الثابت

هوية مؤسسية سعودية الطابع: هادئة ورسمية وواضحة — **دون نسخ هوية جهة حكومية بعينها ودون أي
إيحاء بأن المنصة جهة حكومية**. ينطبق على الهويات الخمس جميعًا.
