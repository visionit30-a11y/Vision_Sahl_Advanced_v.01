# خط أساس البيئة والانحرافات المسجَّلة

يوثق هذا الملف الفارق بين **خط الأساس المعتمد** للمشروع و**ما هو مثبت فعليًا** على جهاز
التطوير. الانحراف يُسجَّل ولا يُغيَّر خط الأساس تلقائيًا؛ أي تغيير في خط الأساس قرار من مالك
المشروع.

|---|---|---|---|

| Node.js | **24** (‏`apps/web/.nvmrc` · وCI يقرأ الملف نفسه) | **24.14.1** | ✅ موحَّد — أُغلق الانحراف |

### خط أساس Node — مغلق

**كان** جهاز التطوير يشغّل Node 24.14.1 بينما خط الأساس المعتمد Node 20، وCI يبني على 20.
**وأُغلق الانحراف باعتماد Node 24 خطًّا أساسًا موحدًا** للتطوير المحلي وCI والبناء.

**سبب اختيار 24 تحديدًا:** Node 20 **انتهى دعمه في 30 أبريل 2026**، أي أن CI كان يبني على
وقت تشغيل لا يتلقى تصحيحات أمنية. وNode 22 لم يعد Active LTS بل صيانة أمنية. **Node 24 هو
Active LTS** حتى أبريل 2028، وهو المثبت على الجهاز أصلًا — فالقرار رفع CI ولم يمس الجهاز.

**مصدر واحد للرقم:** `apps/web/.nvmrc` يحمل `24`، وCI يقرؤه بـ`node-version-file`،
و`package.json` يعلن `engines.node: ">=24 <25"` فيحذّر npm عند إصدار مخالف،
و`scripts/00-check.ps1` يقارن الملف بالمثبت ويطبع `FAIL` عند الاختلاف.

> **ملاحظة ويندوز:** `.nvmrc` **لا يبدّل** إصدار Node تلقائيًا على ويندوز. هو **مرجع
> وحارس** لا مبدّل. تبديل الإصدار يدويًا عبر `nvm-windows` أو `fnm`، والحارس في
> `00-check.ps1` هو ما يكشف عدم التطابق.

**ولا تبعية واحدة تغيّرت بسبب هذا القرار** — لا سبب تقني، والمقفلات كما هي.

## 2. دين تقني مسجَّل

| البند | التفصيل | الاستحقاق المقترح |
|---|---|---|
| ESLint خارج الدعم | `npm install` حذّر: `eslint@9.39.5: This version is no longer supported`. الأداة تعمل بشكل سليم، والتحذير يخص دورة دعم الإصدار لا ثغرة أمنية، ولا يمس كود المنتج. | ترقية إلى الإصدار الرئيسي المدعوم مع بدء **Phase 1** حين يُدخل نظام التصميم قواعد Lint إضافية — لا داعي لتغيير متغيرين في وقت واحد أثناء إغلاق Phase 0 |
| `whatwg-encoding` مهجورة | تبعية غير مباشرة من `jsdom` (بيئة اختبار الواجهة فقط) | لا إجراء — تُحل بترقية `jsdom` لاحقًا |
| تشغيل Redis الفعلي | غير مشغَّل محليًا | قبل إغلاق **Phase 3** — ADR-0003 |
| تحذير إهمال في Starlette | `pytest` يُظهر تحذيرًا واحدًا: `'HTTP_422_UNPROCESSABLE_ENTITY' is deprecated. Use 'HTTP_422_UNPROCESSABLE_CONTENT'`. الاختبارات كلها تمر، والتحذير لا يمس السلوك. لم يُعدَّل الكود عند إغلاق Phase 0 حتى تبقى النسخة المعتمدة مطابقة تمامًا لما اجتاز البوابات وراجعه مالك المشروع | **Phase 1** — استبدال الثابت في `app/core/errors.py` وإعادة تشغيل البوابات |
| العيّنتان مؤقتتان | `TableSpecimen` و`PrintSpecimen` أدوات معاينة تُثبت العقدين قبل وجود محركيهما، وتزولان معهما | **Phase 2 وما بعدها** حين يقرأ المحركان نفس العقود |
| عقدا الجداول والطباعة بلا مستهلك حقيقي | تقرؤهما العيّنتان فقط حتى تصل المحركات | يُغلق مع المحركين |
| محاكاة الطباعة ليست الورق | تقارب معاينة المتصفح ولا تساويها؛ الفحص المرجعي بـCtrl+P | دائم — مسجَّل في ADR-0012 |
| هوامش قاعدة الصفحة | لا تقبل متغيرات مخصصة؛ الهوامش حشوٌ على الحاوية | دائم — قيد لغة لا خيار |
| الاعتماد على `:has()` | يجعل عزل الطباعة مشروطًا بوجود سطح طباعة. مدعوم في المتصفحات الحالية كلها | لا إجراء — مسجَّل في ADR-0012 |
| `IconButton` خارج أنماط الأزرار | يبقى على القياسات العامة، فقد يبدو غير متسق مع نمط زر مضغوط أو فسيح. أُخرج عمدًا لأن إدخاله يجرّ ارتفاعات القشرة كلها | **1B-3 أو Phase 2** بعد رؤية الأثر الفعلي |
| اعتماد `color-mix` | تستعمله عائلتا التنبيهات والنوافذ لحسم شدة اللون والحجاب. مدعوم في المتصفحات الحالية كلها، ولا خطة في المشروع لدعم متصفحات أقدم | لا إجراء — مسجَّل قرارًا في ADR-0011 |
| هامش تباين النبرة المصمتة | نص معكوس على التحذير يعطي 4.69 مقابل حد 4.5 — يمر بهامش ضيق | حارس التباين يثبّته؛ يُراجع إن تغيّر لون التحذير |
| تخزين إعدادات التخصيص في المتصفح | تنفيذ `browserUiSettingsSource` مؤقت: لا خلفية ولا جدول إعدادات. مقصود ومحصور في ملف واحد خلف واجهة غير متزامنة | **Phase 2** — استبداله بنداء HTTP دون لمس أي مكوّن (ADR-0010) |
| طبقة صلاحيات التخصيص مفتوحة | `previewUiPermissions` يمنح الصلاحيتين للجميع لغياب هوية المستخدم. **Seam معمارية لا ضابط أمان**، ومكتوب صراحة في الواجهة وADR-0010 | **Phase 2** — استبدال التنفيذ مع RBAC، والضبط الحقيقي على الـAPI |
| `preview-tenant` معرّف معاينة | ليس جمعية ولا Tenant حقيقيًا: لا سجل ولا عزل. وُجد لإثبات التوريث فعليًا لا نظريًا | **Phase 2** — يزول مع وصول Tenancy الحقيقي |
| مستوى المستخدم غير منفَّذ | مقبول في عقد `resolveUiSettings` ومغطّى باختبار، ولا يُمرَّر في 1B-1 | **Phase 2** — تمرير طبقة إضافية لا إعادة بناء |
| `C:\Program Files\PostgreSQL\15\data` | مجلد بيانات يتيم من تثبيت سابق أُزيلت ثنائياته | **لا يُلمس ولا يُحذف** — ليس ملكًا لهذا المشروع |
