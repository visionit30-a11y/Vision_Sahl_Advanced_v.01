# نظام التصميم

المرجع الحي داخل التطبيق: `/design-system`. هذه الوثيقة تشرح القواعد، والصفحة تعرض النتيجة.

## الطبقات

```
styles/tokens/palettes/*.css   رموز دلالية (لوحة الهوية)
styles/tokens/*.css            مسافات · طباعة · أنصاف · ظلال · طبقات · حركة · نقاط كسر
styles/base.css                إعادة ضبط وعناصر HTML الأساسية
design-system/components/*     مكوّن + وحدة CSS خاصة به
design-system/layout/*         القشرة والتنقل وفتات الخبز
design-system/feedback/*       محرك شريط التنبيهات والحالة
design-system/index.ts         المدخل الوحيد للمكتبة
```

## قواعد ملزمة

| القاعدة | الحارس الآلي |
|---|---|
| لا نص مرئي داخل مكوّن — كل شيء من طبقة الترجمة | `noHardcodedText.test.ts` |
| مفاتيح العربية والإنجليزية متطابقة | `translationParity.test.ts` |
| لا خاصية CSS فيزيائية (`left/right/margin-left…`) | `logicalCss.test.ts` |
| لا قيمة لونية صريحة داخل وحدة مكوّن | `designTokens.test.ts` |
| نقاط الكسر أربع فقط: 640 · 1024 · 1440 | `designTokens.test.ts` |
| الشاشات تستورد المكتبة من مدخلها الوحيد | `importBoundaries.test.ts` |

## الاتجاه

`dir` و`lang` على `<html>` يتبعان اللغة تلقائيًا. الخصائص المنطقية تجعل ورقة أنماط واحدة
تخدم الاتجاهين. الأيقونات الاتجاهية فقط تُعكس عبر `directional` على مكوّن `Icon`.

## الطباعة

عائلة واحدة للعربية والإنجليزية: **IBM Plex Sans Arabic** بأوزان 400/500/600/700، مستضافة
ذاتيًا عبر `@fontsource` بلا أي CDN خارجي. الأرقام **لاتينية** في اللغتين بقرار المشروع،
مثبّتة بـ`font-variant-numeric: lining-nums tabular-nums` لتصطف الأرقام في الجداول المالية.

## الاستجابة

| المدى | السلوك |
|---|---|
| < 640px | تنقل في درج فوق المحتوى، عمود واحد |
| ≥ 640px | شبكات بعمودين حيث يفيد |
| ≥ 1024px | تنقل جانبي ثابت، زر فتح التنقل يختفي |
| ≥ 1440px | عرض محتوى أقصى يمنع الأسطر الطويلة |

لا تُحذف وظيفة على الشاشة الصغيرة؛ يتغير أسلوب العرض فقط.

## شريط التنبيهات والحالة

- مساحته **محجوزة دائمًا بارتفاع ثابت** (`--size-statusbar-height`) — ارتفاع ثابت لا حدًا أدنى،
  فرسالة أطول لا تُكبّر الشريط ولا تدفع المحتوى للأسفل. النص الطويل يُقصّ بثلاث نقاط ونصه
  الكامل في `title`.
- الشريط **ملتصق أسفل الرأس مباشرة**، فتبقى الرسالة مرئية أينما وصل تمرير المستخدم في صفحة
  طويلة، دون أن يحجب المحتوى لأن مساحته محجوزة أصلًا في التدفق.
- واجهة واحدة: `useStatusBar().show({ tone, messageKey, messageValues, link, undo, dismissible, durationMs })`.
- الرسالة تحمل **مفتاح ترجمة لا نصًا جاهزًا**، فتتبع مبدّل اللغة بدل أن تتجمد على لغة لحظة
  إطلاقها. أما رقم السجل في الرابط فبيانات لا تُترجم.
- رابط السجل يظهر بخط أثقل ويُفتح في تبويب مستقل، فلا تفقد الشاشة الحالية حالتها.
- النجاح والمعلومة يختفيان تلقائيًا؛ التحذير والخطأ يبقيان حتى يتعامل معهما المستخدم.
- **لا يُستخدم لأخطاء الحقول** — خطأ الحقل يبقى بجوار الحقل.
- تصفية الروابط حسب الصلاحيات تُضاف في Phase 2 بتغليف المزوّد، دون تغيير عقد الاستدعاء.

## قابلية الوصول

HTML دلالي · تنقل بلوحة المفاتيح · حلقة تركيز واحدة عبر `:focus-visible` · تسميات مرتبطة
بالحقول · حصر التركيز في النوافذ وإعادته عند الإغلاق · رابط «تخطي إلى المحتوى» ·
احترام `prefers-reduced-motion`.
